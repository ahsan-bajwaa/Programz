What You Get

Everything You Need to Audit Your Posture

From IP reputation to CVE lookups — CSAT pulls live threat intel and packages it into a clear, actionable report.

Real-Time Risk Scoring

Aggregates findings from all APIs into a 0–100 risk score with severity classification: Low, Medium, High, Critical.

Interactive Dashboard

Chart.js-powered visualizations: scan history trends, severity breakdowns, and posture over time — all in one view.

PDF Report Export

Generate and download detailed PDF reports per scan. Share findings with your team or submit as evidence.

SIEM Log Forwarding

Every scan action writes to the shared siem_logs table in real time for centralized monitoring.

Role-Based Access

User and Admin roles. Admins get oversight of all scans, user management, and a full audit log panel.

Secure by Design

PDO prepared statements, bcrypt password hashing, session regeneration, and input sanitization baked in from day one.

The Process

Scan to Report in Minutes

Submit your target once. CSAT handles the rest — API calls, scoring, logging, and report generation happen automatically.

Only scan domains, IPs, and URLs you own or have explicit written authorization to test. Unauthorized scanning may be illegal under applicable law.
01
Register & Log In

Create your account with email and password (bcrypt hashed). Role assigned on registration.

02
Submit a Target

Enter a domain, IP, or URL. Server-side validation ensures the format is correct before any API call is made.

03
APIs Run in Background

PHP cURL triggers VirusTotal, AbuseIPDB, Shodan, NVD, URLhaus, and Google Safe Browsing. Results stored in MySQL.

04
View Results & Download Report

Dashboard shows your risk score, severity breakdown, and scan history. Download a PDF report anytime.
